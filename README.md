# Skincare App

Skincare is a cross-platform mobile application designed to help users manage their skincare routines, discover new products, and read informative blog posts. The app features personalized routines, notifications, and a vibrant community section.

## Features

- Personalized skincare routines for different skin types
- Product recommendations and details
- Routine reminders and notifications
- Discover section with blog posts and tips
- User authentication and profile management
